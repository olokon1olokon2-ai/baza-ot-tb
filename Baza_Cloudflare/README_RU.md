# База — ЖК «Олокон» (Cloudflare)

Это стартовый Cloudflare Workers-проект с интерфейсом на русском языке, базой D1 и файловым хранилищем R2.

## Что включено
- Первоначальное создание администратора через секретный код.
- Вход по логину и паролю, сессии в D1.
- Организации и учётные записи инженеров.
- Задания на устранение нарушений, исполнитель, срок и статусы.
- Ежедневный чек-лист обхода.
- Загрузка и скачивание документов через приватный R2 bucket.

## Важно
Это первая рабочая основа, а не завершённая сертифицированная система. Перед реальной эксплуатацией проверьте разграничение доступа, резервное копирование, сроки хранения и требования вашей организации. В текущем MVP документы скачиваются только их загрузившим инженером; администраторский просмотр/выдача доступа к чужим документам ещё требует отдельного согласованного правила.

## Развёртывание

Нужны Node.js и аккаунт Cloudflare.

1. Распакуйте ZIP.
2. В терминале внутри папки выполните:
   `npm install`
3. Создайте D1:
   `npx wrangler d1 create baza-ot-tb`
4. Скопируйте выданный `database_id` в `wrangler.toml` вместо `REPLACE_WITH_D1_DATABASE_ID`.
5. Создайте R2 bucket:
   `npx wrangler r2 bucket create baza-ot-tb-files`
6. Создайте таблицы:
   `npx wrangler d1 execute baza-ot-tb --remote --file=./schema.sql`
7. Задайте секреты:
   `npx wrangler secret put SESSION_SECRET`
   `npx wrangler secret put SETUP_SECRET`
   Для каждого вставьте длинное случайное значение. Не публикуйте эти значения.
8. Запустите тест:
   `npm run dev`
9. Опубликуйте:
   `npm run deploy`
10. Откройте адрес Worker и нажмите «Первоначальная настройка». Введите `SETUP_SECRET`, создайте администратора и войдите.
11. После создания администратора удалите/смените `SETUP_SECRET`, если больше не планируете первичную настройку.

## Примечания
- Приложение рассчитано на Cloudflare Workers + D1 + R2.
- `wrangler.toml` содержит placeholders: обязательно заменить D1 ID.
- Не загружайте секреты в GitHub и не делайте ZIP публичным.
